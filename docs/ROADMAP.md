# Hanim Korean 학생용 자료 라이브러리 로드맵

이 문서는 `korean-lessons` 저장소를 정리하고 학생용 자료 홈페이지로 발전시키는 작업 순서를 고정한다.

## 원칙

- 기존 자료의 내용과 상호작용은 인벤토리 검토가 끝나기 전에는 바꾸지 않는다.
- 홈페이지는 디렉터리를 자동으로 훑지 않고, 검수된 manifest 항목만 보여 준다.
- 개인화 자료는 저장소에 유지할 수 있지만 기본 홈페이지 목록에서는 제외한다.
- `category`, `level`, `format`, `tags`는 서로 다른 역할로 기록한다.
- 중복 파일은 바로 삭제하지 않는다. 대표본을 먼저 지정하고 참조 여부를 확인한 뒤 별도 승인 단계에서 정리한다.
- 111개 자료를 동시에 다시 디자인하지 않는다. 공통 테마 적용 가능성에 따라 묶어서 진행한다.

## 1단계 · 인벤토리와 카테고리

각 HTML 자료에 다음을 기록한다.

- 제목과 한 줄 설명
- 1차 카테고리
  - 한글·발음
  - 문법·문장
  - 어휘
  - 회화·문화
  - 교재별 코스
- 학생용 / 개인화 / 교사용 도구
- 초급 / 중급 / 고급과 필요한 경우 CEFR 하위 단계
- 자료 형식: game, quiz, flashcards, slides, worksheet, role-play, guide, review
- 핵심 태그 3~6개
- 대표본 여부와 관련 버전

완료 조건:

- 모든 추적 HTML이 manifest 또는 제외 목록에 들어 있다.
- 홈페이지에 노출할 항목과 노출하지 않을 항목이 구분된다.

## 2단계 · 태그와 중복 버전

- 태그 표기를 정규화한다.
- 완전히 동일한 파일과 내용상 버전군을 분리한다.
- 각 버전군에 `canonical` 하나를 정한다.
- 이전 URL을 보존해야 하면 redirect/alias를 먼저 만든다.
- 삭제는 별도 승인 후에만 한다.

## 3단계 · 학생용 자료 홈페이지

홈페이지 기능:

- 5개 1차 카테고리
- 초급 / 중급 / 고급 필터
- 제목·설명·태그 검색
- 형식 필터
- 추천 자료와 최근 업데이트
- 빈 결과 안내와 필터 초기화

홈페이지는 `canonical=true`, `status=published`인 manifest 항목만 읽는다.

## 4단계 · 교재별 코스

비공개 Notion의 Course Source Pack을 원본으로 사용한다.

예시:

> 세종학당 한국어 02 → 제1과 → 학습하기 / 연습하기 / 복습하기

AI는 하님이 검수한 어휘·문법·예문·활동을 변환만 하며, 원본에 없는 내용은 `확인 필요`로 반환한다.

## 5단계 · 실용한국어 5·6과 파일럿

- Hanim Forest/Paper 디자인
- 25분 핵심 / 50분 전체 모드
- 영어 숨기기
- 정답·힌트 보기
- 학생 자기 문장
- 역할극
- 모바일·키보드·인쇄·reduced motion 확인

5·6과에서 구조와 디자인을 검증한 뒤에만 1–14과로 확장한다.

## 6단계 · 111개 디자인 정규화

자료를 세 그룹으로 나눈다.

1. **Theme only**: CSS 토큰과 글꼴만 바꾸어도 되는 자료
2. **Component refactor**: 카드·버튼·퀴즈 구조를 공통 컴포넌트로 바꿀 자료
3. **Full redesign**: 내용 밀도와 화면 흐름부터 다시 설계할 자료

공통 디자인 토큰은 한 원본에서 관리하고, 자료마다 팔레트를 복사해 넣지 않는다.
